# Leah's Lemons

A whimsical, feminine summer lemonade landing page built to help Leah's Lemons
get booked for events, festivals, and farmers markets.

## View locally

Open `index.html` in a browser, or serve the folder with any static file server.

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
